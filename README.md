# Stremio HF Space 🐳

A Docker-based deployment setup for hosting a Stremio addon on Hugging Face Spaces.

## Files

- `Dockerfile` — Container configuration for Hugging Face Spaces
- `entrypoint.sh` — Container startup script
- `README.md` — This file

## Deployment

Push to a Hugging Face Space repository. The Dockerfile handles the rest.
